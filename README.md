## 🎨 About This Portfolio

A handcrafted personal portfolio website with a unique **Pencil Sketch & Hand-Drawn Brutalism** paper theme (`#FDF0D5`), custom procedural ink outlines, and `Patrick Hand` handwriting typography.

### ⚡ Portfolio Tech Stack
- **Framework:** Flutter Web (Dart 3+)
- **State Management:** GetX
- **Theme:** Pencil Sketch & Hand-Drawn Brutalism (Zero digital shadows, organic double-pencil outlines)
- **Hosting & Analytics:** Firebase Hosting, Google Analytics 4, Firebase Web SDK

### 📑 What's Inside
- **Chalkboard Splash:** Authentic erased blackboard intro with chalk lettering and full-screen paper expansion (plays once per session via `sessionStorage`).
- **Intro Section:** Hero introduction, profile illustration, and quick call-to-action buttons.
- **About Section:** Background story, core values, and development metrics.
- **Projects Section:** Interactive sketch cards showcasing flagship mobile and web applications.
- **Contact Section:** Direct hand-drawn inquiry form with real-time field validation.
